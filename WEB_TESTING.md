# Browser pilot

Open https://kurbanovaanna12-jpg.github.io/JuAnnji/ in Safari, rotate the iPhone horizontally, then tap Играть.
Left: jump (hold for height). Right: movement joystick; up/down climbs vines.
The browser build is a Godot 4.7.2 single-threaded Compatibility export.
GitHub Pages source: main branch, /docs folder. No cross-origin isolation headers required.

The docs folder contains the ready-to-serve release. Export a new Web release as index.html with threads disabled to update the game. Preserve the custom launch page, updating its Engine config fileSizes when replacing the exported binaries.
