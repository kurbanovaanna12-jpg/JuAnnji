# Исправленная сборка v2

Источник: parts_v2.png, создан встроенным image_gen по hero_side_idle.png.
Задание генерации: шесть прозрачных деталей в сетке 3x2, строго правый профиль;
единая голова с волосами, туловищем и шортами; плечо; предплечье с кистью;
бедро; голень; ботинок. Сохранить внешность, очки, цвета, одежду и стиль.
Исключить фронтальные ракурсы, подписи, тени и нарисованные окружности суставов.

hero_rig.gd использует равномерное масштабирование каждой детали, уточнённые
положения плеч, локтей, коленей и лодыжек. Конец бедра подрезан внутри
AtlasTexture для перекрытия голенью. Голова, корпус и шорты теперь цельные.
Старая текстура parts.png сохранена, но больше не используется.

Проверка: рендер неподвижной позы и двух фаз бега (check_v2.png), запуск
основной сцены на 120 кадров без ошибок скриптов. Ручное прохождение не выполнялось.
Остаются видимые линии стыков при большом увеличении. Кисти на лиане пока
не привязаны точным IK. Отражение влево зеркальное.

Настройки HeroRig: Run Cycles Per Second — частота бега;
Blend Speed — скорость перехода поз; Preview Run — демонстрация бега.
Для просмотра открой hero_rig_preview.tscn и нажми F6.
